# Machine-assisted provisional labels

`dictionary_baseline_v1.csv` contains transparent rule-based labels generated from the source-blinded annotator-A packet. It is a review aid and conventional baseline only. It is **not** an independent human annotation set and must not be used to claim inter-annotator agreement, classifier validation, factual calibration, or an observed media effect.

Every `factual_calibration` value is `unverifiable` because the process inspected only retained headline/post text and did not compare claims with the original publication context or official information available at publication. Human annotators should review the items independently using the project codebook, then preserve the model output for error analysis.
